# Security Policy

## Supported versions

During the beta, only the latest published version of each package receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Report the vulnerability privately through
[GitHub security advisories](https://github.com/shopanaio/storefront/security/advisories/new).

Include the affected package and version, a description of the issue, and steps to reproduce.
We acknowledge reports within a few business days and keep you informed until a fix is released.
